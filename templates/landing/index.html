Risiko Tidak Patuh Regulasi

PMK No. 24/2022 mewajibkan integrasi SATUSEHAT. Klinik tanpa sistem digital siap terkena sanksi.

Pengalaman Pasien Buruk

Data Rentan Hilang

Integrasi Resmi
SATUSEHAT Kemenkes

Sesuai amanat PMK No. 24 Tahun 2022, seluruh fasilitas kesehatan wajib mengintegrasikan data ke SATUSEHAT. DokterKlik melakukannya secara otomatis untuk Anda.

Sinkronisasi Otomatis via FHIR R4
Data Patient, Encounter, Condition, Observation, dan MedicationRequest dikirim otomatis setelah dokter simpan SOAP.
Validasi ICD-10 Otomatis
Kode diagnosis divalidasi sesuai standar internasional sebelum dikirim ke SATUSEHAT.
Retry & Monitoring
Jika gagal sync, sistem otomatis retry hingga 5× dengan exponential backoff. Failure rate > 10% langsung alert ke admin.
OAuth 2.0 & Enkripsi End-to-End
Autentikasi aman menggunakan Client Credentials. Token dan data medis dienkripsi menggunakan Fernet (AES-128).

Pertanyaan yang Sering Diajukan

Ya, DokterKlik menggunakan standar HL7 FHIR R4 untuk berkomunikasi langsung dengan API SATUSEHAT Kemenkes. Setiap data rekam medis yang disimpan oleh dokter otomatis disinkronkan — termasuk data Patient, Encounter, Condition, Observation, dan MedicationRequest. Sistem juga memiliki retry mechanism untuk memastikan tidak ada data yang terlewat.

Keamanan data adalah prioritas utama kami. Semua data medis dan PII (seperti NIK) dienkripsi menggunakan Fernet (AES-128) saat disimpan di database. Transfer data dilakukan melalui HTTPS/TLS 1.3. Data disimpan di data center Indonesia, mematuhi UU PDP No. 27/2022. Kami juga mencatat audit log untuk setiap akses data medis.

DokterKlik adalah aplikasi berbasis web (SaaS), jadi Anda tidak perlu menginstal apa pun. Cukup buka browser di komputer, tablet, atau smartphone, login, dan langsung bisa digunakan. Kami merekomendasikan browser Chrome, Firefox, Safari, atau Edge versi terbaru.

Pasien cukup mengirim pesan ke nomor WhatsApp klinik yang sudah terhubung dengan DokterKlik. Chatbot otomatis kami akan memandu pasien untuk memilih dokter, tanggal, dan jam kunjungan. Pasien juga bisa menerima notifikasi antrean, pengingat kontrol, dan resep digital langsung di WhatsApp.

Proses setup awal hanya membutuhkan waktu 15-30 menit. Anda cukup mendaftar, mengisi profil klinik, menambahkan dokter dan staf, lalu langsung bisa mulai melayani pasien. Tim kami juga tersedia untuk membantu proses onboarding jika diperlukan.
